# Разработчик. сайты - приложения - чат-боты

Создаю с помощью AI-инструментов цифровые решения для бизнеса и личных задач — от сайтов и чат-ботов до приложений и CRM-подобных систем.

## Кейсы

| Проект | Описание | Пример |
|---|---|---|
| **Сайт-визитка / лендинг** | Представление специалиста или компании, форма записи и уведомления о заявках. | ![Пример сайта-визитки](images/2026-11-02_16-50-13.png) |
| **Калькулятор строительных услуг** | Расчёт стоимости услуги и отправка заявки с фиксацией обращения и уведомлением. | ![Форма калькулятора](images/2026-11-02_17-00-17.png) |
| **Чат-бот салона красоты** | Информация о салоне и запись к свободному специалисту в сообществе ВКонтакте с возможностью связаться с администратором. | ![Пример диалога с ботом](images/1.png) |
| **Sport Tracker для Android** | Личный трекер результатов, тренировок и абонементов. | ![Sport Tracker](images/apk-sport_tracker.png) |
| **Stroy Tracker** | Учебный MVP для управления строительными проектами и задачами: Kanban-доска, фильтры, перетаскивание карточек и прогресс проекта. | [Открыть демо](https://sybolay.github.io/stroy-tracker/) · ![Stroy Tracker](images/2026-11-02_16-54-17.png) |
